# Vaibhvee Prakash Portfolio

A modern, responsive personal portfolio built with React and Vite.

## Features

- Modern UI with smooth scrolling
- Galaxy-inspired black and blue theme
- Animated 3D sphere
- Skills section
- Projects showcase
- GitHub and LinkedIn links
- Fully responsive design

## Tech Stack

- React
- Vite
- JavaScript
- Tailwind CSS
- Framer Motion
- Three.js

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
