# Vaibhvee Prakash Portfolio

A modern, responsive personal portfolio showcasing my skills, projects, and experience as a Computer Science Engineering student. The portfolio features a clean, galaxy-inspired design with smooth animations and an interactive user experience.

## About

This portfolio was built to highlight my technical skills, featured projects, and professional journey. It is designed with a focus on performance, responsiveness, and modern web design.

## Features

- Responsive design
- Smooth scrolling animations
- Interactive user interface
- Skills showcase
- Project showcase
- Resume section
- GitHub and LinkedIn integration

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Three.js

## Installation

Clone the repository:

```bash
git clone https://github.com/Vaibhvee012/vaibhvee-portfolio.git
cd vaibhvee-portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build the project:

```bash
npm run build
```
